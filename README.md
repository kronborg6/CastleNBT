# CastleNBT

A small C++23 library for creating and serializing Minecraft NBT
(Named Binary Tag) data.

CastleNBT is primarily a learning project created while working on
CastleCraft, my own Minecraft server implementation.

> **Status:** Early development — version `0.1.0`
>
> Version 0.1.0 focuses on creating NBT structures and serializing them
> to the binary NBT format. Reading/parsing NBT is planned for a future
> release.

## Features

- C++23
- Create all standard NBT tag types
- Nested compounds
- Homogeneous NBT lists
- Byte, Int and Long arrays
- Binary NBT serialization
- Big-endian numeric encoding
- Serialize directly into `std::vector<std::uint8_t>`
- CMake build system
- GoogleTest test suite

## Requirements

- C++23 compatible compiler
- CMake 4.2 or newer

GoogleTest is required when building the tests.

## Building

Clone the repository and configure the project:

```bash
cmake -S . -B build
cmake --build build
```

The main library target is:

```text
castleNBT
```

A small development/testing executable is also built as:

```text
castleNBTTool
```

## Running the tests

Configure the project with testing enabled:

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build
```

The serialization tests compare the generated byte stream directly
against expected NBT binary data.

## Usage

Include the main CastleNBT header:

```cpp
#include <castle/nbt.hpp>
```

### Creating a compound

```cpp
#include <castle/nbt.hpp>
#include <cstdint>
#include <vector>

using castle::nbt::Nbt;

int main() {
    auto root = Nbt::makeCompound("");

    root.add(Nbt::makeString("name", "Steve"));
    root.add(Nbt::makeInt("health", 20));
    root.add(Nbt::makeFloat("speed", 0.1f));

    std::vector<std::uint8_t> data = root.compile();
}
```

`compile()` returns the serialized NBT document as a byte vector.

You can also serialize into an existing buffer:

```cpp
std::vector<std::uint8_t> data;

root.compile(data);
```

### Nested compounds

Compounds can contain other compounds:

```cpp
auto root = Nbt::makeCompound("");

auto player = Nbt::makeCompound("player");

player.add(Nbt::makeString("name", "Steve"));
player.add(Nbt::makeInt("health", 20));

root.add(std::move(player));

auto data = root.compile();
```

This represents an NBT structure similar to:

```text
{
    player: {
        name: "Steve",
        health: 20
    }
}
```

### Lists

NBT lists must contain elements of the same tag type.

```cpp
auto root = Nbt::makeCompound("");

auto inventory = Nbt::makeList("inventory");

auto sword = Nbt::makeCompound("");
sword.add(Nbt::makeString("id", "minecraft:diamond_sword"));
sword.add(Nbt::makeInt("count", 1));

auto pickaxe = Nbt::makeCompound("");
pickaxe.add(Nbt::makeString("id", "minecraft:diamond_pickaxe"));
pickaxe.add(Nbt::makeInt("count", 1));

inventory.append(std::move(sword));
inventory.append(std::move(pickaxe));

root.add(std::move(inventory));

auto data = root.compile();
```

CastleNBT checks that elements added to a list use the same NBT tag
type.

Primitive values can also be appended directly:

```cpp
auto numbers = Nbt::makeList("numbers");

numbers.append(std::int32_t{10});
numbers.append(std::int32_t{20});
numbers.append(std::int32_t{30});
```

### Arrays

CastleNBT supports the three NBT array types:

```cpp
auto root = Nbt::makeCompound("");

root.add(Nbt::makeByteArray("bytes", {1, 2, 3}));
root.add(Nbt::makeIntArray("ints", {100, 200, 300}));
root.add(Nbt::makeLongArray("longs", {1000, 2000, 3000}));
```

## API overview

NBT values are created using the static factory functions on `Nbt`:

```cpp
Nbt::makeByte(...)
Nbt::makeShort(...)
Nbt::makeInt(...)
Nbt::makeLong(...)
Nbt::makeFloat(...)
Nbt::makeDouble(...)
Nbt::makeByteArray(...)
Nbt::makeString(...)
Nbt::makeList(...)
Nbt::makeCompound(...)
Nbt::makeIntArray(...)
Nbt::makeLongArray(...)
```

Compound children are added with:

```cpp
compound.add(...);
```

List elements are added with:

```cpp
list.append(...);
```

NBT structures are serialized with:

```cpp
std::vector<std::uint8_t> data = root.compile();
```

## Motivation

CastleNBT was created as part of my work on CastleCraft, a Minecraft
server project written from scratch.

Rather than using an existing NBT library, I wanted to implement the
format myself to better understand binary serialization, byte ordering,
recursive data structures and the Minecraft protocol ecosystem.
